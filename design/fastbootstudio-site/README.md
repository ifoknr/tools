# Fastboot Studio site (sample)

A sample landing page for Fastboot Studio (Windows) with Fastboot Studio Mobile and Companion.
IFOKNR chose option A on 3 Nov 2026: the apps' grey and blue-slate, with glowing card edges and
gradient icon tiles taken from a Figma community landing page. More is to come before it goes live.

Open `index.html` from this folder through a local server at the repository root
(`python3 -m http.server`, then `/design/fastbootstudio-site/`). `?lang=en` shows English.
It uses the live site's icons, names, videos and fonts from `site/assets/`.
