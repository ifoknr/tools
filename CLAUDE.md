# Notes for Claude sessions on this repository

This repository is ifoknr.com (the site, `site/`), the Telegram bot (`bot/`) and the shared
brand files (`brand/`).

## Commits and pull requests
They show IFOKNR only: no Co-Authored-By or session lines in commit messages or pull request
descriptions.

## Brand (fixed: change only when IFOKNR asks)
The full guide and the source files are in `brand/` (BRAND.md). In short:
- IFOKNR's mark is `IF` in the Swamp Ninja lettering on a soft deep-violet tile, and the name is
  `IFOKNR` in the same lettering, lilac to violet to rose on dark (darker violets on light).
  The apps and tools use these. On an About page: mark, name, "Developer" under it.
- ifoknr.com uses a new mark and name: `IF` and `IFOKNR` in the Audiowide lettering, a graphite
  tile, the name silver on dark and graphite on light.
- App and tool names are drawn in the Prixma Bold Italic lettering, small.
- Each app and tool has a fixed icon, never violet. The root tools' icons are grey (graphite
  tile, calm grey-blue lines, since 30 Oct 2026); the Fastboot Studio apps' are glass (since 9 Nov
  2026, `brand/icons/glass/`): grey glass in dark, frosted with a blue glyph in light.
- Never commit a font file (personal-use licences): text is drawn as outlines.
- Numbers in English digits in every language.
